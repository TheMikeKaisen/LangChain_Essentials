## What is LangChain?
LangChain is a powerful framework that makes it easy to build applications powered by AI models. Think of it as a toolkit that connects your code to powerful brains (like ChatGPT, Gemini, or Claude).

## Repository Structure
Currently, this repository contains practical examples broken down by topic:
- **1_Models**: This folder covers the absolute basics—how to connect to and communicate with different AI models.

### Getting Started
1. **Environment Setup**: Ensure you have a `.env` file in this root directory with your API keys (like `OPENAI_API_KEY`, `GOOGLE_API_KEY`, etc.).
2. **Install Dependencies**: Run `pip install -r requirements.txt` to install all necessary Python packages.
3. **Explore**: Navigate to `1_Models` and read the READMEs inside each subfolder to start learning!
