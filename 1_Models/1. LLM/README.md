# 1. LLM (Large Language Models)

## What is an LLM?
LLM stands for **Large Language Model**. These are AI models that have read vast amounts of text on the internet and can understand and generate human-like text. 

In the context of LangChain, "LLMs" refer to models that take a simple string of text as input and return a simple string of text as output. They are essentially advanced autocomplete machines.

## What's in this folder?
- **1_llm.py**: A basic script showing you how to connect to a foundational LLM and ask it a question or give it a prompt.

*Note: In modern AI development, you will more commonly use "Chat Models" (covered in the next folder) rather than pure LLMs, but this is an important foundational concept!*
